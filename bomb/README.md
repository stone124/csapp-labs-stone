# Bomb Lab 命令速查

下面的解压命令要在压缩包所在目录执行；解压后进入归档文件创建的目录，再运行后续命令。

## 解压与运行

```bash
tar -xvf bomb.tar
cd bomb
./bomb
```

如果归档解压出的目录名不是 `bomb`，将 `cd bomb` 中的目录名替换为实际名称。

也可以把已通过阶段的答案逐行保存在文本文件中，让 bomb 先读取文件，再从终端读取：

```bash
./bomb answers.txt
```

空行会被忽略。答案文件读到文件末尾后，程序会继续从标准输入读取。

## GDB 调试

```bash
gdb ./bomb
```

常用 GDB 命令：

| 命令                          | 用途                               |
| ----------------------------- | ---------------------------------- |
| `break main`                | 在`main` 函数设置断点            |
| `run`                       | 启动程序                           |
| `continue`                  | 继续运行到下一个断点               |
| `stepi` / `si`            | 单步执行一条汇编指令               |
| `nexti` / `ni`            | 单步执行，遇到函数调用时不进入函数 |
| `info registers`            | 查看寄存器                         |
| `x/<数量><格式><单位> 地址` | 查看指定地址的内存                 |
| `quit`                      | 退出 GDB                           |

### 查看内存示例

`x` 是 examine（查看内存），一般写作 `x/<数量><格式><单位> 地址`。数量省略时默认查看 1 项；地址也可以用寄存器表达式，例如 `$rsp + 8`。

| 命令 | 用途 |
| --- | --- |
| `x/s $rdi` | 把 `$rdi` 指向的内存按字符串显示，直到遇到 `\0` |
| `x/wd $rsp` | 查看栈顶的一个 4 字节 `int`，按有符号十进制显示 |
| `x/6dw $rsp` | 从栈顶开始，连续查看 6 个 4 字节整数 |
| `x/wx $rsp + 8` | 查看 `$rsp + 8` 处的 4 字节值，按十六进制显示 |
| `x/gx $rsp + 0x20` | 查看 `$rsp + 32` 处的 8 字节值，按十六进制显示 |
| `x/ga $rsp + 0x20` | 把该处的 8 字节值按地址显示，可能附带符号名 |
| `x/8bx $rsp` | 从栈顶开始，逐字节查看 8 字节的十六进制内容 |
| `x/5i $pc` | 从当前指令地址开始，反汇编显示 5 条指令 |

常用格式：`s` 是字符串，`d` 是有符号十进制，`u` 是无符号十进制，`x` 是十六进制，`a` 是地址，`i` 是汇编指令（不是整数）。

常用单位：`b` 是 1 字节，`h` 是 2 字节，`w` 是 4 字节，`g` 是 8 字节。这里的 `w` 是 GDB 的单位名称；本实验中的 `int` 占 4 字节，指针占 8 字节。查看字符串或指令时，无需指定单位。

格式和单位的顺序可以互换，例如 `x/wd` 与 `x/dw` 等价。未指定的格式、单位通常沿用上次设置；写全可以明确本次查看方式。

## 导出汇编文件

```bash
objdump -d bomb > bomb_disassembly.txt
```

查阅工具帮助和手册：

```bash
apropos gdb
man gdb
info gdb
man ascii
info gas
```

Bomb Lab 的核心方法是阅读反汇编并用 GDB 跟踪执行、检查寄存器和内存；不要靠暴力猜答案。不同课程版本的阶段数和评分规则可能不同，具体以随 bomb 提供的 writeup 为准。
